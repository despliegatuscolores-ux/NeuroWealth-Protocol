# 🧠 NeuroWealth Protocol | Reprogramación Financiera Cognitiva

La diferencia entre la libertad financiera y el estancamiento crónico rara vez es puramente matemática; suele ser neurológica. **NeuroWealth Protocol** es una Single Page Application (SPA) diseñada para identificar, mapear y reestructurar los bloqueos subconscientes y creencias limitantes que las personas heredan de su entorno sobre el dinero y la generación de valor.

Utilizando principios de neuroplasticidad, psicología conductual y reencuadre cognitivo (PNL), esta herramienta permite al usuario auditar su "código fuente" financiero y establecer un protocolo de sanación y abundancia en 21 días.

## ✨ Fases del Protocolo

*   🔬 **Fase 1: Escáner Subconsciente:** Un test clínico diseñado para evocar respuestas automáticas e identificar fricciones en cuatro áreas clave: *Herencia Cognitiva de Escasez, Fricción en la Recepción de Valor, Sesgo de Suma Cero* y *Apego Basado en el Miedo*.
*   🕸️ **Fase 2: Topografía Neural (Dashboard):** Un mapeo visual poligonal (gráfico de radar) que ilustra dónde se concentran los bloqueos y traumas financieros del usuario.
*   🛠️ **Fase 3: Taller de Reestructuración (Toolkit):** Ejercicios de reencuadre cognitivo, protocolos de perdón financiero, auditoría de neuronas espejo (entorno) y enfoque del Sistema Activador Reticular (SAR).
*   📝 **Fase 4: Protocolo de 21 Días (Exportable):** Generador de un plan de acción y declaraciones de identidad descargable en formato `.txt` para consolidar los nuevos circuitos neuronales mediante repetición.

## 🛠️ Arquitectura y Stack Tecnológico

La aplicación ha sido desarrollada bajo un paradigma **Privacy-First** y **Zero-Build**. Toda la información clínica e introspectiva del usuario es estrictamente confidencial.

*   **Sin servidores ni bases de datos:** Todo el procesamiento ocurre de forma local en el navegador del cliente.
*   **Almacenamiento persistente:** Uso de `localStorage` para mantener el progreso del usuario sin comprometer sus datos.
*   **UI/UX:** [Tailwind CSS](https://tailwindcss.com/) (vía CDN) con una estética clínica, moderna y soporte nativo para Modo Oscuro/Claro (Dark Mode).
*   **Reactividad y Estado:** [Alpine.js](https://alpinejs.dev/) para gestionar la lógica interactiva de manera fluida y declarativa.
*   **Visualización de Datos:** [Chart.js](https://www.chartjs.org/) para el renderizado del mapa de vulnerabilidades.

## 🚀 Despliegue Inmediato

Al ser una aplicación web estática, no requiere instalación de dependencias (`npm`) ni compilación.

**Opción A: Ejecución Local**
Simplemente descarga el repositorio y abre el archivo `index.html` en cualquier navegador web.

**Opción B: Alojamiento en GitHub Pages**
1. Ve a la pestaña `Settings` de este repositorio.
2. Navega hasta la sección `Pages` en el menú izquierdo.
3. En "Build and deployment", selecciona la rama `main` (o `master`) y guarda. 
4. En pocos minutos, la aplicación estará funcional y pública en la web.

## 📚 Fundamento Teórico

El modelo de intervención de esta herramienta se apoya en:
*   **Neuroplasticidad autodirigida:** La capacidad del cerebro para formar nuevas conexiones sinápticas en respuesta al aprendizaje y la repetición de nuevos estímulos.
*   **Reestructuración Cognitiva:** Técnicas de Terapia Cognitivo-Conductual (TCC) para identificar y disputar pensamientos automáticos irracionales sobre el dinero.
*   **Disonancia del Entorno:** Cómo las *neuronas espejo* fuerzan la adaptación de nuestras expectativas financieras a la media de nuestro círculo social cercano.
